# Bitcoin Market Sentiment vs Hyperliquid Trader Performance

## Objective

Analyze the relationship between Bitcoin market sentiment and trader performance using Hyperliquid trading data and the Fear & Greed Index.

## Datasets

- Hyperliquid Historical Trading Data
- Bitcoin Fear & Greed Index

## Methodology

1. Data Cleaning
2. Data Integration
3. Sentiment Analysis
4. Trader Performance Analysis
5. Direction Analysis
6. Position Size Analysis
7. Correlation Analysis

## Key Findings

- Greed periods generated the highest average profit per trade.
- Fear periods produced the highest trading activity.
- BUY trades outperformed during Fear.
- SELL trades outperformed during Greed.
- Larger positions generated significantly higher profits.
- Sentiment alone showed weak predictive power.
